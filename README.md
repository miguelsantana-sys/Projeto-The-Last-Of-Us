# Projeto-The-Last-Of-Us

Site de três páginas sobre o jogo **The Last of Us**, desenvolvido como atividade acadêmica.

> Este projeto foi criado para fins educacionais e não possui fins comerciais. The Last of Us e suas imagens pertencem à Naughty Dog e à Sony Interactive Entertainment.

## Sobre o projeto

O objetivo da atividade é praticar a criação de páginas web com HTML e CSS, usando uma estrutura comum de cabeçalho, menu de navegação, conteúdo principal e rodapé. O tema escolhido foi o jogo The Last of Us.

## Páginas

- **Home:** apresentação do projeto, com banner e texto sobre o tema.
- **Biografia:** história do jogo, personagens principais, trilha sonora e evolução da franquia.
- **Contato:** formulário de mensagem e informações para falar com a equipe.

## Tecnologias utilizadas

- HTML5
- CSS3

## Como executar

1. Baixe ou clone o repositório:
```
   git clone https://github.com/seu-usuario/projeto-tlou.git
```
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `Home.html` no navegador, ou use a extensão **Live Server** para ver as alterações em tempo real.
